# Support

OpenBIMI is maintained in public and community support is best-effort.

## Get help

- **Setup help:** Follow the [setup wizard](https://openbimi.com/setup) or read the [BIMI guides](https://openbimi.com/guides).
- **Reproducible bugs:** Submit a [bug report](https://github.com/suped-com/openbimi/issues/new?template=bug_report.yml).
- **Ideas and feature requests:** Submit a [feature request](https://github.com/suped-com/openbimi/issues/new?template=feature_request.yml).
- **Security vulnerabilities:** Use the private process in [SECURITY.md](SECURITY.md).

Before posting, remove credentials, private DNS data, email contents, and personal information. DNS records are often public, but screenshots and exports can contain unrelated sensitive configuration.

If a guide is unclear or missing a step, open an issue with the page URL and the specific gap. General privacy or terms questions can also go in the issue tracker; use the private security channel for sensitive information.
