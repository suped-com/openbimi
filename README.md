# OpenBIMI

Free, open tools to set up, validate, and understand BIMI without an account.

- Production: [openbimi.com](https://openbimi.com)
- Repository: [suped-com/openbimi](https://github.com/suped-com/openbimi)

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
pnpm lint
pnpm typecheck
pnpm build
```

## Deployment

The project is deployed through Vercel. Pull requests receive preview deployments and the `main` branch deploys to production.

## Project status

The initial infrastructure scaffold is live. Product development follows the approved OpenBIMI implementation plan.
